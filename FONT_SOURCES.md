# Font sources

The Arabic interface uses **Montserrat Arabic** webfont files from the public [typeagm/Montserrat-Arabic](https://github.com/typeagm/Montserrat-Arabic) repository. The source repository provides webfont files and identifies the **OFL-1.1** license. The six used weights (400, 500, 600, 700, 800, and 900) are served through jsDelivr from that public source rather than a platform-specific development path, so they remain accessible after deployment on Render Static Site.

The Latin interface loads **Montserrat** from Google Fonts. Montserrat is distributed under the SIL Open Font License.
